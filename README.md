# camforme
캠 원격제어기

사진 라벨을 기준으로 Xiaomi/Mijia Mi 360° Home Security Camera 2K Pro (MJSXJ06CM)용 개인 제어 앱 시제품을 구성했습니다.

## 실행

`index.html`을 브라우저에서 열면 화면을 확인할 수 있습니다. 마이크 권한은 HTTPS 또는 localhost에서 실행할 때 브라우저가 허용합니다.

## 현재 포함된 화면

- 한국어 로그인 화면과 로그인 후 대시보드
- 카메라 영상 연결 대기 영역, 방향 패드, 작동 토글
- 기본 음소거, 누르는 동안만 마이크 권한을 요청하는 푸시 투 토크 버튼
- 작은 화면에 맞춘 반응형 레이아웃

## 보안 및 연동 상태

로그인은 UI 시연용입니다. 이메일/비밀번호를 검증하거나 인증하지 않으며, 화면 안에 입력한 계정 이메일만 세션 스토리지에 보관합니다. 실제로 개인 한 명만 접근하게 하려면 서버 측 계정 인증, 안전한 세션 쿠키, 요청 권한 검사와 감사 로그가 필요합니다. 이 시제품은 비밀번호를 저장하거나 네트워크로 보내지 않습니다. 실제 계정 비밀번호를 입력하지 마세요.

카메라 영상, 회전, 전원, 음성 제어는 아직 연결되지 않았습니다. GitHub의 [`tsunglung/xiaomi-360-hacks`](https://github.com/tsunglung/xiaomi-360-hacks) 지원표에는 MJSXJ06CM에 Telnet만 표시되며 RTSP/ONVIF는 표시되어 있지 않습니다. 해당 프로젝트는 카메라를 분해하고 UART로 수정 펌웨어를 기록해야 하며 보증이 깨질 수 있다고 경고합니다. 기기 펌웨어를 변경하거나 Telnet을 인터넷에 노출하지 마세요.

실기 연동 전에는 공식 Mi Home/Xiaomi Home 제어와 별도로 사용할 수 있는 제조사 승인 API/SDK가 있는지 확인해야 합니다. 그렇지 않으면 별도 앱에서 이 모델을 안전하게 제어할 수 있다고 보장할 수 없습니다. 이 UI는 연동되지 않은 동작을 성공한 것처럼 표시하지 않도록 연결 대기 상태를 보여줍니다.
